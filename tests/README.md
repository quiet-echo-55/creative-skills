# 验证方法

本地 test-prompts.json 使用 skill 与非空 cases，每例包含 id、prompt、expect。跨技能 disability-regression.json 使用非空 cases，每例包含 id、prompt、must、must_not。它们声明行为预期，不要求固定措辞。现有字段保留，补充 id 用于定位案例。

2.3 新增 [16 例受众与身体关注回归](devotee-regression.json)及 7 例本地任务，合计 118 例行为期望。其中兼顾明确审美任务与普通任务、细节充分性与不过度修复、穿戴选择与读者偏好、衣料遮挡与白色盲眼结构。实际试用的输入、原始输出与局限见 [2.3 评审](REVIEW-2.3.md)，未运行的案例不能称为通过。

## 自动检查
```bash
python scripts/validate_repo.py
python scripts/test_validate_repo.py
python scripts/validate_release.py
```

检查 manifest、技能名称和正文、占位标记、测试结构、重复 ID、内部 Markdown 文件链接，并确认当前发布树没有 `archive/`。只解析本仓库使用的内联 Markdown 链接，检查文件／目录目标，不检查外部网络链接或标题锚点；它不是完整 Markdown 解析器。
这三条命令不生成文章、不调用绘图模型，也不判断医学正确性或文学质量。历史测试的 100% 路由分数不能作为产物验收。

## 3.0 新增类型、困难与主题回归

`v3-regression.json` 提供 30 个跨技能行为期望，覆盖 LBK 与经股区别、复合肢体状态、瘫痪与眼部结构、设备故障与延续、身体审美/动态残态、长期人物主体性和非目标任务不误触发慕残关注。每例的 `must/must_not` 是人工评审依据而非字符串字面匹配；必须运行目标模型且人工审阅后才能声称通过。补丁静态检查不等于产文质量评定。

## 行为评审
逐个读取所测技能和必要引用，将 prompt 作为用户任务运行；对照 expect 或 must/must_not，记录实际输出、问题位置与理由。新增案例还须检查没有被过度纠正的正常情况，例如自然的重复、接受帮助、同类身体的不同人物。

写作对照涵盖 [六组示例](../writing-natural/examples.md)：日常、细致观察、帮助选择、对白、义眼连续性、组合缺失。每组检查身体事实、动作资源、视角与人物声音、是否重复解释。示例的“生硬”段是构造反例，不冒充旧版模型实测输出。

绘图评审涵盖 [四组提示词](../visual-continuity/prompt-template.md)：残肢与连裤袜、上肢缺失与手占用、义眼戴／取下、多人及镜像。另用本地 mirror 案例检查用户明确要求全身镜像时不裁切回避。评审文本可复制性、正向结构、构图与材质、局部修正保留项。

需要严格比较旧版与新版时，采用相同模型版本、参数、输入和上下文范围，各自加载对应提交的技能，保存原始输出后盲评。此次仓库升级不预填这种尚未运行的模型成绩。参见 [2.1 审阅记录](REVIEW-2.1.md) 与 [2.2 收尾记录](REVIEW-2.2.md)。

2.2 共保留 54 例本地行为案例、23 例身体跨技能回归，并新增 18 例蒸馏回归；合计 95 例行为期望。新增覆盖长期情绪变化、无明确诱因的幻肢感、顺利适配、双向经验传递、独立提示词和移除 archive 后的调用。它们是待目标模型执行的验收任务，不等于已通过的生成测试。
