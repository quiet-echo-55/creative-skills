# Assistive Devices & Prosthetics

## 1. 工具先问任务

不要先问“残疾人应该用什么”，先问：**这一场要完成什么，以及角色想用什么方式完成？**

目标可能包括：长距离移动、短距离稳定、腾出手、节省体力、正式场合外观、速度、运动、工作、保护身体、跨越特定地形或世界观能力。

## 2. 按任务检查器械信息

- `STATE`：正在用 / 穿戴 / 未用 / 放附近 / 不在场 / 损坏 / 维护；
- `LOCATION`：在身体、手里、轮椅上、墙边、包内或其他位置；
- `CONTROL`：如何控制；
- `SUPPORT`：提供什么支撑；
- `HAND_COST`：占用哪只手/是否需要双手；
- `TASK_FIT`：适合哪些当前任务；
- `MAINTENANCE`：清洁、充电、校准、耗材等是否相关；
- `FAILURE`：什么情况下能力下降或不可用。

只记录已知且有关的项目，不为填表发明维护周期或故障。复杂动作优先确认状态、位置、控制、支撑和手占用。

## 3. 移动辅具

可包括：

- 手杖；
- 前臂拐/肘拐；
- 腋拐；
- 单根或一对拐杖；
- 助行架/助行器/rollator；
- 手动轮椅；
- 电动轮椅；
- 运动/场景专用轮椅；
- 转移板、扶手、淋浴椅等任务工具；
- 世界观支撑器具。

不要硬套“某类拐杖必须成对”“某侧绝对不可交换”“轮椅使用者一定不能站”等旧语料规则。具体使用方式由身体功能、器械结构、训练和场景决定。

## 4. 下肢假肢

至少登记：

- 与身体连接/接受方式；
- 是否存在人工关节；
- 支柱/主体结构；
- 假脚或末端接触件；
- 当前穿戴；
- 适用任务与限制。

### 简单刚性棍腿 / peg / stilt

可以把它建模为“接受/固定部分 + 刚性支柱 + 末端接触件”。如果明确**没有膝关节**：

- 不会在天然膝位置自行屈曲；
- 坐下、楼梯、狭窄空间时的姿态会受到刚性结构影响；
- 是否取下、向前伸、使用特殊长度或其他技巧由具体设定决定，不写成唯一规则；
- 末端可能是防滑垫、专用脚或其他结构，是否穿鞋取决于设定。

### 有人工膝/踝/足的系统

每个关节能力单独登记。不要用“高级假肢”一句话自动获得天然关节全部能力。

## 5. 上肢义肢

区分：

- 外观/装饰；
- 被动支撑；
- 体动/机械控制；
- 肌电或其他电子控制；
- 活动专用终端；
- 科幻/魔法驱动。

明确抓握、旋转、肘功能、力量、速度、精细控制、触觉和反馈是否存在。义手可以很有用，但不是“天然手等价物”的默认替换。

## 6. 轮椅

记录手动/电动、角色是否在椅中、刹车/转移状态、腿/残肢支撑、物品放置、地形和是否携带其他辅具。

轮椅是移动工具，不是“失败方案”，也不自动证明角色完全不能站立或步行几步。

## 7. 义眼与视觉设备

普通外部义眼主要恢复外观，不恢复缺失眼的视觉。先确认眼部结构及装置类型；眼球仍在时也可能使用美容义眼片，不能仅凭“义眼”推断眼球整体缺失。详见 [眼部专项](../ocular-loss/SKILL.md)。

科幻/魔法视觉装置若能看见，必须登记传感、连接、视野、能源、延迟/限制和失效条件。

## 8. 适配与反馈

需要写假肢/器械适配时使用：

`目标 → 试用 → 身体/任务反馈 → 调整 → 再试`

不要从旧小说语料复制固定厘米、角度、分钟或“一定这样穿”的参数。器械参数不能反过来否定角色已经出现的疼痛、摩擦、疲劳或任务失败；如果剧情需要医学处理，应另找可靠来源而不是由本 Skill 开处方。

## 9. 鞋袜与衣物

器械会改变衣物拓扑：接受腔、关节、支柱、假脚可能撑起裤腿、丝袜或裤袜；简单支柱末端可能没有普通鞋。具体规则与 `disability-foundation` / `visual-continuity` 共用。

## 10. 物件叙事

磨损、贴纸、备用件、定制外观、遗失、借用、维修都可以让器械成为人物物件。但顺序是：**先是工具，再是人物物件，最后才可能成为象征**。不要让器械象征性压过角色本身。

## 11. 技术描述的边界
腋拐的常规承重通过手柄传到手，不把腋托压住腋窝当作主要承重方法。前臂拐套环的形状、是否闭合及能否临时留在手臂上取决于型号；挂在前臂上不等于仍提供有效承重。
折叠能力、支数、持侧、步态、适用地形与穿鞋调整要根据具体装置和使用者条件描述。不要照搬存档的固定重量、固定鞋跟高度、唯一上楼顺序或“高手无风险”。
假肢接受腔、内衬、残肢袜和悬吊方式存在不同组合，不给所有角色强制同一穿戴层数。上肢义肢能抓住物品不代表适合承受全身体重。
适配中的不适是实际反馈，不必每次安排失败；没有依据不提供处置处方、统一恢复时限或疼痛阈值。可用来源见 [来源与适用范围](../docs/SOURCES-AND-DESIGN.md)。

写适配对话、日常穿脱或维护带来的任务变化时，读取 [场景方法](../writing-physicality/scene-methods.md)；写物件的线索、关系或情节作用时，读取 [故事方法](../writing-story/story-methods.md)。
