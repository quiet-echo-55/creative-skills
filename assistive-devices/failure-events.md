# 辅具故障、失落与恢复：事件方法

本文件用于用户明确要求器械不可靠、故障、脱落、遗失、跌落或失去支撑的剧情。真实器械通常不是一次性道具：区别**失效模式**与**失效后果**，不编造发生频率、统一缺陷或处理处方。参考设备既有型号、身体状态及已建立环境。

## 1. 从具体事件到状态变化

先问：

1. 这是器械固有故障、错误使用／适配、环境事故、被挪走、遗失，还是主动取下？它们不能混同。
2. 哪个**具体功能**丧失：承重、控制、固定、转向、外观、视觉矫正、抓握或可达性？
3. 事件前设备在哪里、由谁持有；事件后落在哪里、是否仍接触身体、能否触及？
4. 哪些承重点、可用手、姿势、衣物轮廓随之改变；是否产生新的风险或可用策略？
5. 角色的应急经验、备用件、他人帮助、维修可能性是否在前文建立？若没有，不要瞬间凭空出现。

建议内部记：`DEVICE_ID / BASE_CAPABILITIES / BEFORE_STATE / TRIGGER / FAILED_FUNCTION / AFTER_STATE / LOCATION / RECOVERY_OPTIONS / CONTINUITY_COST`。若用户不要求，不向正文输出这张表。

## 2. 前臂拐、腋拐、手杖、助行器

候选事件：防滑端条件改变、握把松动、构件出现损坏、滑落、落到不可及位置、遗失、被别人未经商量移走。真实断裂须有可信的材料、受力或先前状态线索，不把每次踏到水面都写成拐杖折断。

- 支撑仍在时可以及时坐稳或调整，未必摔倒；失去关键承重时先写剩余支撑与落脚。
- 套环留在前臂不等于杖尖还在承重；落到地上的拐杖不会自动回手。
- 若只剩一只天然承重腿，是否能跳移、扶物或地面挪动由 TASK_SKILLS、距离、地面与疲劳决定。

## 3. 下肢假肢

区分接受腔／悬吊、人工膝、支柱、假脚及外观件；异常关节卡滞、固定不稳、接受腔不适、零件损坏、意外脱落，对应不同结果。不能笼统“假肢坏了，所以整条腿突然没了”。

- **功能下降**：仍穿戴但某一动作不可靠，人物可能决定坐下、停止继续走、移至安全处。
- **部件或固定失效**：若导致装置脱离身体，先写重心、当前支撑与脱离后的落点；不是所有型号都可在正常活动中轻易脱落。
- **主动取下**：人物知道取下动作，另记取下后的衣物折线、残肢位置、移动模式及装置去向；不应被误写成意外坠落。
- **后续**：维修、替换、备用设备、暂时不使用、改变行程都可选；未解决故障不能下一章自然消失。

## 4. 上肢义肢

可出现抓取失败、握持物滑落、连接松脱、控制异常或电源问题；先看义肢类型。被动外观义手本来就不应承担自然手的精细工作；功能型义肢也不是天然手完全等价品。受损后物件由谁拿着、腾出了哪只手、是否仍可支撑，都要更新。

## 5. 轮椅与转移

区分轮胎／轮圈、刹车、脚踏／扶手、动力、电控、坡道障碍、未稳定转移及坐姿滑落。不能从“轮椅坏了”直接推出“人从椅上飞出去”。

- 椅子不能推进时，人物可能仍能安全坐着；掉落则是另一项独立事件。
- 从轮椅滑落到地面后，记录身体落点、轮椅方向、刹车情况、控制器／手机与固定支点距离。
- 双腿完整但瘫痪依旧有实体位置和重量；站起能力、感觉、上肢与躯干功能逐人核对。
- 如果没有合适恢复手段，可以写暂时停留和求助，别让“意志力”替代转移资源。

## 6. 义眼、眼镜与眼部装置

外观义眼、覆盖既存眼部结构的美容义眼片、眶内植入物、天然失明眼球是不同的东西。仅对可取下的外部装置，才可能安排外部义眼意外移位、脱出或遗失。事件条件须与具体装置、场景相容；不把固定植入物写成日常掉出的玻璃球。

- 义眼掉落后区分地面位置、是否被发现、是否可找回、是否受污损；没有义眼不自动出现血腥伤口。
- 普通外观义眼并不恢复视觉，因此掉落后主要变化通常是外观、佩戴感受或社交处境；不能让失明眼突然失去此前不存在的视觉。
- 如果同时失去矫正眼镜，另算有视觉眼的功能变化，不能与义眼事件合并。
- 社交性窘迫由人物处境与意愿决定，不把每名使用者写成必然羞耻。

## 7. 连锁事件也须限制升级

一次事件可以牵动一连串后果，例如拐杖倒向远处、手机在跳移时滑出包、不得不改为坐姿移动；但每个新环节都需自己的物理桥梁。不能为了增加戏剧性让全部设备同一秒毫无原因地同时损坏。

已损坏器械的状态要贯穿下一场：`损坏但仍可见`、`留在某处`、`维修中`、`替换件已到`、`再次可用` 分别记录，不自动复位。世界观器械也遵守已设定的能力和故障逻辑。

## 8. 原创场景：拐杖离手

她右腿还能承重，左侧大腿残肢没有穿假肢。雨刚停，她在楼道平台上把背包改背到肩后，左手从前臂拐握把松开的一瞬，拐杖顺着墙滑倒，杖头滚到下一阶。她先握住扶手，右脚踏稳，再往下面看了看。距离够得着，却不能站在台阶边贸然弯下身。她把另一根拐杖靠牢墙，先坐到最上一级，把背包挪到膝旁，才一点点探身去捞。楼上的门开了，有人问需不需要帮忙。她没抬头：“帮我拿那根，别碰我的包。”

此处的重点是支撑与控制权：她提出了具体协作，并没有因此改变身体结构或突然丧失全部行动能力。
