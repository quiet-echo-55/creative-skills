# 身体差异与截肢类型字典：单一权威入口

用途：接收用户输入的简称并转为可验证的 **侧别 × 天然结构 × 实际功能 × 当前装置**。本字典只提供结构范围和路由，不编写人物性格、审美偏好、故障概率、动作步骤，也不替用户决定截肢残肢具体长度。动作检查交给 `writing-physicality`，辅具能力交给 `assistive-devices`，身体观察交给 `writing-natural`。

## 解析次序

1. 先解析侧别 `L/R/B`（左/右/双侧），保留用户自己的表述；再解析截肢层级，最后处理组合。同一缩写在不同社群可能另有所指，出现歧义时结合已知角色资料；不能把历史内部名称当世界通用医疗术语。
2. 结构字段逐侧登记：肩、上臂、肘、前臂、腕、手；髋、大腿、膝、小腿、踝、足。关节存在并不自动代表主动运动或负重能力。
3. 精确层级未确定时留 `unknown`。用户只有“缺一条腿”不默认为经股；“失明”不默认为眼球缺失；“瘫痪”不默认为身体部位消失。
4. 组合状态逐肢登记，不靠 OOE、三肢缺失等标签代替解剖。已有角色设定高于本字典的通常含义。

## 常见输入与规范化

| 输入或社区简称 | 中文对应 | 边界与现役路由 |
|---|---|---|
| SAK / AK / AKA（单侧语境） | 单侧膝上／经股截肢 | 保留一定大腿及髋部活动可能；该侧天然膝、小腿、足不存在；`amputation-transfemoral` |
| LAK / RAK | 左／右膝上截肢 | 与 SAK 同层级，另锁定侧别；`amputation-transfemoral` |
| SBK / BK / BKA（单侧语境） | 单侧膝下／经胫截肢 | 保留天然膝与一段小腿；足与相应远端缺失；以 Foundation 和本字典为主 |
| LBK / RBK | 左／右膝下截肢 | LBK 的 L 是 left，不是另一种截肢手术；与经股有不同坐姿、衣物及假肢构造 |
| SAE / AE | 单侧肘上／经肱截肢 | 保留部分上臂与肩部运动可能；该侧天然肘、前臂、手不存在；`amputation-transhumeral` |
| LAE / RAE | 左／右肘上截肢 | 与 SAE 同层级，加侧别 |
| SBE / BE | 单侧肘下／经桡截肢 | 保留天然肘与部分前臂；手缺失；用 Foundation 与 Physicality，不套经肱专项 |
| LBE / RBE | 左／右肘下截肢 | 同上，加侧别 |
| BAK / DAK | 双侧膝上截肢 | 分别记录左右残肢与两个髋部及装置，不能套用单腿跳模型 |
| BBK / DBK | 双侧膝下截肢 | 左右天然膝均可能保留，但是否可动、承重依具体功能设定 |
| BAE / DAE | 双侧肘上截肢 | 两侧分别登记，不凭空出现能抓握的天然手 |
| BBE / DBE | 双侧肘下截肢 | 保留天然肘与残存前臂；可用抓握与义肢功能另记 |
| OOE（**本仓库历史用法**） | 上下肢组合截肢／缺失 | 不是国际统一医疗分级，更**不是双臂截肢的同义词**；`combined-limb-loss` 加命中的层级模块 |
| KD / ED | 膝离断 / 肘离断 | 与经股、经肱的保留结构不同；不能自动互换 |
| HD / SD | 髋离断 / 肩离断 | 髋离断不保留经股的大腿段；肩离断不保留经肱的上臂段；骨盆及肩带切除另行定义 |
| partial foot / partial hand | 足或手的部分缺失 | 精确哪些趾、掌/跖、踝、腕存在；不能直接套经胫或经桡 |

上表缩写并非全部受统一标准约束：建议小说正文仍使用自然中文“左腿膝下截肢”“右臂肘上截肢”等；内部结构状态可采用规范术语 `transfemoral / transtibial / transhumeral / transradial`。不要未经核实就把某个社群缩写说成普适的医学缩写。

## 非截肢类型的正交维度

- **单眼失明、浑浊盲眼、眼球缺失、外观义眼、覆盖在尚存眼球表面的美容义眼片**：分别记录 `GLOBE_STRUCTURE`、`VISION`、`OCULAR_DEVICE`，详情只在 `ocular-loss` 定义。
- **截瘫／四肢瘫／单肢瘫／肌力不足／关节活动受限**：保留天然肢体是否存在与衣物支撑；分别登记主动运动、感觉、躯干平衡、负重、膀胱等相关功能（仅当角色设定或任务需要），不能用“瘫痪”推断统一感觉、诊断或独立能力。
- **复合状态**：例如“左经胫截肢 + 右经肱截肢 + 左眼失明”，分别叠加结构、功能、视觉及器械，并在资源冲突任务中计算手占用与可用支撑。

## 不需要新的根 Skill

结构与简称解释在此处单一维护；现有经股、经肱、组合、眼部专项只维护命中范围内的特殊边界。膝下、肘下、双侧、多肢、瘫痪等若没有独立专项，以 Foundation + 本字典 + Physicality + Devices 组合运行；发现具体新例外时可追加此处或独立参考，不按缩写数量无限新增根 Skill。

## 快速验收示例

- `LBK, left knee retained, no left foot, no prosthesis`：不能写该侧天然膝消失，也不能让她左足落地；若无人工支撑，是否跳、拄拐或坐轮椅须再判断。
- `SAK + SAE on the same side`：两条残肢保留范围分别判定，常规两手拄双拐可能不具备相应资源，除非另有合适装置和训练。
- `bilateral paralysis without limb loss`：两条天然腿仍完整撑起裤袜与裤腿；不能画成空腿筒。
- `blind milky right eye with intact globe`：右眼存在但无视觉，不能凭“白眼”加义眼或空眼窝。
