# 移动与动作类型参考

## 1. 步行与步态不对称

“跛行/一瘸一拐”是对**步态不对称**的描述。它可能来自疼痛、无力、关节活动受限、腿长差、假肢使用或其他状态，但不要仅凭一个视觉标签反推诊断。

如果角色没有形成左右交替的步态，例如无假肢时依靠单腿连续跳移，那么直接写“跳移/单腿跳”通常比笼统写“一瘸一拐”更准确。

## 2. 单腿连续跳移

先检查：

- 哪条腿实际承重；
- 是否有拐杖/扶手/墙面；
- 双手是否空闲；
- 地面摩擦、落差、湿滑和拥挤；
- 角色对这种移动是否熟练；
- 距离与疲劳是否值得在剧情中体现。

熟练可以让动作更经济，不会取消落地冲击、平衡和环境条件。

## 3. 短跳转移

床边到椅子、洗手台前的小幅重定位、放下假肢后几步到近处等，可以是少量短跳或旋转转移。不要把几步转移扩写成长期移动模板。

## 4. 拐杖 / 助行器

关注：

- 支撑点数量；
- 哪只手被占用；
- 需要开门、拿物或战斗时如何腾手；
- 楼梯、坡道、湿滑地面是否改变策略；
- 单拐、双拐、手杖、助行器之间不能仅凭名称推导唯一动作序列。

## 5. 轮椅

记录：手动/电动、是否在椅中、刹车与转移状态、腿/残肢支撑、地形、物品位置。轮椅使用者是否能站立、走几步或使用假肢由角色状态决定，不能从“坐轮椅”反推完全不能站。

## 6. 爬行、跪行与地面移动

“爬过去”至少要知道接触面：

- 双手/单手/前臂；
- 膝；
- 完整足；
- 残肢是否接触或悬空；
- 是否有护垫、衣物或地面保护。

不要默认把敏感残端直接当作膝盖或脚掌承重。若世界观或角色训练允许特殊承重，需要显式建立。

## 7. 地面恢复与转移

从地面到站立/轮椅/床椅是独立任务。检查：

- 可用手和腿；
- 辅具是否落在可及范围；
- 附近是否有固定支撑；
- 是否先转到跪/坐/半跪等中间位置；
- 疲劳、伤势和环境是否改变方案。

不要求固定步骤；只要求动作链有物理桥梁。

## 8. 器械切换

假肢步行 → 脱下假肢 → 拿拐杖，或轮椅 → 转移 → 站立，都需要状态变化。器械不会在需要时自动出现在手上，角色也不会在没有过渡时瞬间切换承重方式。
