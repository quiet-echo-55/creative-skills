# 身体结构参考

本文件只用于**描述层级和连续性**，不是临床诊断指南。

## 下肢

可以按需要从宽到细描述：

- 足部/部分足缺失；
- 踝附近缺失；
- 膝下/经胫；
- 膝关节附近/膝离断；
- 膝上/经股；
- 髋关节附近/髋离断；
- 更近端骨盆范围差异。

关键不是背术语，而是明确：髋、膝、踝、足哪些天然结构仍在，以及残肢终点在哪里。

髋离断不保留该侧天然大腿段；不能沿用经股残肢的长度、抬残肢动作或裤料支撑。髋离断与涉及骨盆切除的情况也不能互相替代：骨盆、臀部软组织、疤痕与坐姿支持按实际设定判断，不自动写成半个臀部消失或只能歪坐。身体终点已知而表面形态未知时，不从术语编造统一皮肤、凹陷或骨突。

## 上肢

可以按需要区分：

- 手指/部分手；
- 腕附近；
- 肘下/经桡；
- 肘关节附近；
- 肘上/经肱；
- 肩部附近；
- 更近端肩带范围差异。

同样优先写保留关节与残肢终点。

## 多肢体状态

每一条肢体分别登记 side + structure + function。不要用“双重截肢”“上下肢组合缺失”“四肢残疾”等总标签替代每一侧事实。

## 非缺失型状态

对于瘫痪、无力、活动范围受限、感觉缺失、疼痛等情况：

- 先保持天然结构完整性；
- 再单独降低对应功能；
- 服装、遮挡、肢体数量和视觉轮廓仍按结构事实处理。
