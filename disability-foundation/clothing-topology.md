# 服装拓扑参考

## 1. 先画“支撑图”，再写“空”

对一件衣物的每个通道回答：

1. 天然身体支撑到哪里？
2. 残肢是否继续支撑一部分？
3. 假肢/义肢是否在衣物内部？
4. 从哪个点开始真正没有支撑？
5. 空置段是垂下、折起、塞入、固定、打结、卷起还是已经改短？

“空袖/空裤腿/空袜筒”只描述**无支撑段**，不等于整条衣物通道从根部开始为空。

## 2. 袖子

- 肩/上臂/前臂残肢存在时，袖子在对应段仍有体积；
- 短袖/无袖可能直接显示残肢；
- 长袖无支撑段可自然下垂、摆动、折叠、固定或塞入；
- 上肢义肢佩戴后，袖型由义肢结构重新支撑；
- 完整但瘫痪/无力的手臂仍然把整条袖子撑起来。

## 3. 裤子与裙装

- 髋部、大腿残肢、小腿残肢对应不同裤腿支撑终点；
- 假肢在裤内时，接受腔、膝单元、支柱、假脚会改变布料折线；
- 真正空裤腿可垂下、卷起、固定、塞入或改短；
- 裙装可能暴露也可能遮挡身体结构，取决于长度、坐姿、动作和镜头，不能写成统一“更方便/更不方便”。

## 4. 袜、丝袜、过膝袜、长筒袜

这些通常是左右独立的腿部单件。可能出现：

- 只在完整腿穿一只；
- 覆盖残肢并在终点以后形成空袜筒；
- 穿在假肢外；
- 根据造型折叠、固定或改短。

如果是独立袜类，“只穿一只”本身不需要制造一条不存在的第二腿。

## 5. 裤袜 / 连裤袜 / tights

把它视为：

`共享腰胯区 + 左腿筒 + 右腿筒`

缺失侧腿筒常见的**可能处理**包括：

- 上段覆盖残肢，残肢终点以后成为空袜筒；
- 空袜筒折回/卷起/塞入腰胯或裙摆下；
- 定制剪短或缝合；
- 被假肢完整或部分撑起。

这些都是可选方案，不是所有人物的固定穿法。

如果该腿**完整但不能运动**，腿筒仍有天然腿完整支撑，不能生成空袜筒。

## 6. 鞋

- 天然足存在：按普通鞋袜逻辑；
- 有假脚：是否穿普通鞋取决于假脚和任务设定；
- 简单棍腿/支柱末端若是防滑垫或专用端头，可能没有鞋；
- 不要仅根据“天然脚有几只”推导画面中鞋的数量。

## 7. 动态

无支撑衣料有惯性和重力：走动、单腿跳、轮椅移动、转身、风、坐下时都会改变悬垂方向。被别针、绑带、折叠或塞入的衣料则遵守固定方式，不应同时又像完全自由的布条一样飘动。
