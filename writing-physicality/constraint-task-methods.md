# 身体资源缺口与高难任务：写作方法

本文件是 Creative Skills 2.3 的按需增补：当用户要求身体条件造成的困难、危险动作、任务失败、窘迫或明确的残态时读取。仍以既有 BODY_STATE、TASK_SKILLS、SCENE 为事实源，不生成统一的“残疾难度等级”。角色可熟练、会适应，也可能当场受阻；不要强制每章出事故。

## 1. 任务—资源差分

先定义眼前目标，并把抽象的“需要两只手/两条腿”拆成具体资源：

1. 哪个动作要求两个同时工作的固定／操作点、连续落脚、躯干稳定、双侧视觉，或某个可达高度？
2. 此人有哪些天然结构、可用功能、已训练技巧和辅具？哪些当前离手、失灵、被占用？
3. 环境还能提供哪些稳定资源：桌沿、扶手、座面、墙、物品夹持、同行者、时间、光照？能否安全可靠地使用？
4. 角色会先试哪种方法？若失败，物体、姿态、手占用、位置、体力和时间怎样改变？
5. 采取第二方案、等候、求助、推迟、失败或部分完成，哪一种最符合该人物与主线？

“任务需要双手”不等于单臂角色绝对做不到；“只有一条腿”不等于会自动不断跳。可行性由具体动作链、适配工具与训练决定。

## 2. 复杂任务的写作闭环

`当前目标 → 资源缺口 → 有依据的尝试 → 反馈/失衡 → 身体与物件新位置 → 改变办法 → 实际结果 → 延续后果`

这是内部审查顺序，不是八段固定文风模板。正文写得够具体即可：一处被占用的支撑、一个失败的细节、一个有后果的选择，往往比整段诊断解释有效。

## 3. 分身体条件的原创难题库

### 仅一条天然腿可承重；经股截肢且未戴假肢

- 双手抱住箱子又要通过无扶手门槛：原有手持物与扶墙/拿拐资源冲突。可以放下箱子、先安置可用辅具、分批移动；着急也可能先坐到低处调整。
- 雨后人行道需要急停、转弯或倒退：承重脚的落点、湿滑与惯性重要；不能只说“跳得很稳”。
- 已经坐在地上，最近的椅子略高：看完整腿位置、手能否撑稳、残肢是否受压、鞋袜和物件是否妨碍，再决定能否恢复。

### 仅一只天然手可抓握

- 拉紧需要双向受力的绳结、封口或衣物：完整手既要固定又要拉动。用桌沿、夹具、身体侧压、预先安装的固定装置或协作；残臂能否辅助取决于保留长度、功能、可承受接触。
- 端盘并开门：盘子和门把争夺同一只手；需要临时放盘、以可及固定面改操作或求助。
- 穿戴一件需同时拉住两端的服装：可分步骤、坐下、借支点，不凭空生成第二手。

### 双臂缺失／上下肢组合缺失

- 手机掉到床后、控制器远离轮椅：先检查能否接近、操作、呼叫，地面移动时哪些身体面可承重。
- 跌倒后只有单侧天然腿可支撑：不要用不存在的天然手肘撑地；必须检查躯干、腿、器械、家具和已建立的训练，允许原地等待支援。

### 完整双腿但瘫痪或功能严重受限

- 坐轮椅伸手取低处物件导致躯干重心变化：刹车、座位姿势、躯干功能和腿部位置各自核对。腿仍是实体，不会变成空裤腿。
- 转移中座面错位：区分主动挪动、滑落、转移失衡及他人协作；下地后轮椅是否仍可控制，不能凭空回座。
- 穿裤、重新安置脚踏板上的足、长时间坐姿调整：根据已锁定主动运动、躯干控制与感觉状态，不把“瘫痪”一词自动推成全身无感觉。

### 单眼失明／眼部差异

- 一边观察细小文字一边注意另一侧有人过来：头部转动有时间成本；不能让失明眼补看。
- 另一只有视觉的眼还近视且镜片沾水：区分眼镜可用、现场光线、任务辨认与义眼外观，不把单眼视觉自动归为失去所有距离判断。

## 4. 残态要落到物理关系

场景真正改变时，优先记录可见且有意义的六个维度：

- **位置**：站、坐、倚靠、跪／爬、趴或侧卧；与附近支点距离如何变化。
- **承重**：完整足、假脚、轮圈、座面、可承重的手或经验证的残肢接触；不能凭空承重。
- **占用**：哪只手握东西、扶墙、操作控制器；腾出后谁接手支撑。
- **肢体与衣料**：残肢方向、衣物在支撑终点后的空置、固定过的袜筒或空袖、假肢从穿戴转为不在身上后的轮廓变化。
- **视线和触觉**：叙述视角能看到什么；遮挡下的皮肤与未建立的敏感、疼痛不可凭空出现。
- **残余选择**：她能够改变哪一处位置、使出什么技巧或提出什么协作要求。

不要用“她的残缺暴露无遗”“可怜地瘫在那里”代替上述信息；也不要让每场变成医学动作说明。用户明确要求特写时可以停留更久。

## 5. 失败不必是跌倒，跌倒不必立即爬起

失败也可能是打不开、拿不到、搬不动、超时、绕路、错过活动、求助对象不在、设备被他人拿错。真正跌倒时先交代原因与落点，再检查下地后的任务：哪一处身体撑着、辅具掉在哪里、物品是否被压住、能否叫人、能否借稳定家具。恢复、再次失衡、换移动方式或暂时停留都是可能结果。

## 6. 小场景示范：困难从动作中出现

**示例 A｜经股截肢、当前未戴假肢、单足可承重、双手完整，熟练短跳。**

她把纸箱从门口抱起来，才发现门是向自己这边开的。右脚往后挪了半步，鞋底停在门垫边。箱子挡着视线，她伸不出手握门把，也不能把原本靠在墙角的拐杖隔着箱子勾过来。她试着用手肘顶开门，门弹回了一点，箱底又压到了胸前。“行。”她把箱子放回地上，扶住门框站稳，先把门抵开，再一点点把纸箱挪过门槛。等她腾出手去找拐杖时，门后的人已经问了两次怎么还没来。左侧裤腿空着的部分被她折在大腿残肢下方，搬箱时松开了一角；她坐到矮凳上重新压住那道折边，回了一句：“被你们这扇门耽误了。”

**示例 B｜左侧上臂截肢，右手完整，左肩可主动移动，右手正扶在座椅边。**

拉链的底端总跟着布料往上跑。她用右手捏住拉链头，试了两次，衣服前襟都在腰侧堆成一团。她坐回椅子，把衣摆压在腿和椅面之间，重新对好卡齿。第三次总算拉上了。出门时她仍忘了带钥匙，站在门边骂的却是自己，不是那件衣服。

**示例 C｜双腿仍在但无法主动移动，轮椅使用者，躯干平衡能力由本场已知设定决定。**

她俯身去够落在脚踏板旁的笔，椅背离开肩膀的那一刻就知道伸得太远。左手忙着握扶手，右手收回来时只碰到笔帽。她重新坐稳，看了一会儿脚踏板上摆着的两只鞋，拿起桌边的伸取器；今晚赶稿，她没兴趣为一支笔冒险。若剧情确实需要跌落，另写失衡条件与地面恢复，不把此例当成自动掉椅的公式。

## 7. 长篇去重复

同一角色前一次尝试会留下经验：下次也许提前分装、带备用工具或更熟练地要求协助；不同场景又会失去不同资源。困难可以由场景变化、目标、时间压力、人物关系或器械失效制造，而不是随机剥夺能力。安稳完成的日常和静止身体观察同样是有效章节。
