# Writing Physicality

## 1. 方法：任务 → 资源 → 约束 → 动作链

遇到“她怎么做 X”，先回答：

1. **任务目标**是什么；
2. 哪些身体结构**存在**，哪些功能**可用**；
3. 此刻有哪些承重点和支撑点；
4. 哪些手/肢体被拐杖、轮椅、物品、扶手占用；
5. 环境提供哪些支撑或风险；
6. 角色对**这个任务**熟练到什么程度；
7. 是否值得特写。

内部确认必要的动作连接；正文按视角和节奏选择展开程度，不规定节点数量。不要用“艰难地完成”替代动作，也不要为了真实感把每个普通动作都写成康复训练。

## 2. 先分动作类型

### 步行 / 假肢步态

只有在角色确实以脚、假脚或其他步态支撑形成连续步行时使用。步态可以对称或不对称。

### 跛行 / 一瘸一拐

它描述**不对称步态**，不是“缺一条腿”的通用标签。无假肢状态若实际靠单腿连续跳，就直接写跳移，不要为了词感硬写成跛行。

### 单腿连续跳移

检查承重腿、落点、平衡、支撑物、手占用、地面、距离和疲劳。熟练意味着更经济，不意味着湿滑、落差或落地冲击消失。

### 短跳转移

床边、浴室、桌边等少量重定位可以只跳几步。它与长距离跳移的节奏、风险和叙事权重不同。

### 爬行 / 跪行 / 地面移动

先写接触面：手、前臂、膝、完整足、残肢或护垫到底哪一处接地。不要默认把残端直接当膝盖或脚掌承重；若角色确实会这样做，先建立其保护、耐受与训练条件。

### 轮椅 / 扶物 / 他人协助

都属于不同资源结构：轮椅需要转移和地形状态；扶物需要可用固定点；他人协助需要位置、关系与协作动作。

## 3. 支撑与重心

动作可信度优先检查：

- 承重面在哪里；
- 重心向哪里移动；
- 支撑点是否足够；
- 要腾手时原来的支撑去哪；
- 从站到坐、床到椅、地面到站立有没有中间路径；
- 器械切换是否有拿起、放下、穿戴、转移等桥梁。

正文不必讲术语，但作者内部必须能回答。

姿态随支撑与任务改变：坐下时可能向更稳的一侧偏，站立时重心更多落在可承重的腿上；残臂可随肩膀轻微移动，单眼人物可能转头补看，失去双手的人可用肩膀与躯干调整坐姿。跌倒后也可以先停留在地上处理物品与下一步，不急着恢复整齐姿势。只取本场真实发生的变化，不把这些动作写成所有相同身体状态者的固定姿势。

## 4. 日常任务

可处理：起床、换衣、袜/丝袜/裤袜、洗澡、如厕、厨房、购物、开门、行李、楼梯、坡道、车辆上下、床/椅/地面转移、整理辅具、休息。

重点是“任务如何被重新组织”：

- 先坐下再穿；
- 先靠好拐杖再腾手；
- 把物品分两次移动；
- 利用桌沿、墙面、扶手、身体夹持；
- 调整站位/转头补足视觉信息；
- 直接换移动模式，而不是强行维持同一种方式。

具体顺序不是通用固定公式；不同器械、身高、车辆、楼梯、训练和偏好会改变动作链。

## 任务真的卡住时
遇到必须同时用两手固定与操作、用双侧支撑、快速连续落脚或兼顾两侧视野的任务，先看角色此刻是否有足够资源。若没有，不能用“她熟练地完成了”跳过缺口。写清至少一个实际尝试和它为何有效或失败：桌沿固定、身体压住、换工具、重新站位、请人协作、暂缓或放弃都可选。残肢或义肢参与夹持与承重须有已建立的结构和能力；腾出一只手也要交代原来的支撑去哪。
熟练可以减少犹豫与无效动作，也可能让人物在熟悉路线上移动得更快；突发障碍、湿滑、疲劳或设备离手仍可能打断原方案。一次失败以后，物品、姿势、器械和任务目标都要跟着更新。

## 5. 服装动作

当剧情涉及空袖、空裤腿、袜筒、丝袜/裤袜时，先由 Foundation 确定衣物支撑拓扑，再写动作：

- 残肢范围内衣料仍有体积；
- 空置段可以垂下、折起、固定或被整理；
- 连裤袜缺失侧的腿筒如何处理要与共享腰胯结构一致；
- 完整但瘫痪的腿仍在衣物里，只是主动运动/承重不同；
- 假肢穿入后衣物轮廓和穿脱动作会变化。

## 6. 跌倒与恢复

跌倒按动作、环境和人物当下状态发生，不设固定次数。在以独腿或多肢缺失人物为核心的长篇，持续保留失衡风险和起身条件，不能为动作利落而让相关风险长期消失。发生时检查：

- 为什么失衡：地面、碰撞、误判、疲劳、器械故障等；
- 如何保护身体；
- 辅具掉在哪里；
- 起身/转移是否需要附近支撑；
- 情绪由人物决定，不自动羞耻或励志。

在长期故事中，跌倒可以发生在熟练人物身上。把跌倒写成有前后连接的事件：先交代失衡条件，再追踪落地姿势、完整肢体与残肢的位置、器械落点、附近支撑和下一步任务。起身、转移、求助或暂时留在原处都是可能结果；事后的疼痛、延误、衣物和关系变化按实际场景延续。
双上肢缺失同时只有一条天然腿可用时，若没有可承重的上肢义肢、稳固家具或可及的协助，地面恢复可能成为重大难题。保留残肢的长度与功能、另一条腿的状态、当前装置、环境和训练仍逐人判断，不把这种组合直接写成绝对无法站起。

“忘记缺失肢体而下意识发力”可以是偶发身体图式错位，但不能高频打卡。

## 7. 幻肢与身体感知

幻肢/幻痛是可选变量。若出现：

- 区分位置感、姿势感、触感、痒、痛等；
- 不把感觉写成实体承重；
- 诱因和应对服从角色既有经验；
- 不写未经建立的固定发生频率、恢复时间或医疗方案。

## 8. 疲劳与环境

不要用一个统一“残疾疲劳值”。疲劳来自当前任务：连续跳移、长距离轮椅推进、拄拐、假肢摩擦、持续站立、战斗或恶劣地面可能消耗不同资源。

环境是动作的一部分：雨雪、湿滑、碎石、楼梯、拥挤、狭窄、黑暗、坡道会改变速度、支撑策略和器械选择，但不会自动让熟练角色失去能力。

## 9. 细节剂量与熟练度

身体细节可服务动作、人物、关系、风险和连续性，也可来自感官观察与审美。默认细致且自然融入；不强制每笔细节推动剧情，也不为展示结构打断正在发生的事。

熟练度按任务记录：平地 A、湿滑 C、无假肢床边转移 A、陌生楼梯 B。不要用“截肢几年”或“用了几年拐杖”直接替代每项能力。

## 10. 禁止模板

- 不固定“没假肢就跳”；
- 不固定“单腿角色一定跛”；
- 不固定“爬行一定用残端承重”；
- 不固定“某类拐杖只能一对/只能某侧”；
- 不固定上楼、下楼、上车只有一套动作；
- 不把残疾等同于拒绝帮助；
- 不为真实感强塞未经锁定的厘米、分钟、年限等精确数值。

## 11. 组合

结构/功能语义由 `disability-foundation` 提供；具体经股/经肱/组合/眼部边界由 `amputation-transfemoral` / `amputation-transhumeral` / `combined-limb-loss` / `ocular-loss` 提供；器械能力由 `assistive-devices` 提供；本 Skill 负责把它们变成可执行动作链。

自然表达参见 [改写例集](../writing-natural/examples.md)，可靠事实与旧语料的边界见 [来源说明](../docs/SOURCES-AND-DESIGN.md)。

需要展开日常、衣物改造、公共空间、幻肢感知、适配或护理场景时，读取 [场景方法与例句](scene-methods.md)；普通动作简写不必加载全部素材。
