# 受众关注与人物回应

在用户明确要求慕残取向、持续的身体审美、相关恋爱关系或读者定位时读取。普通残疾人物创作不自动启用这套取向。来源与限制见 [研究记录](../docs/DEVOTEE-RESEARCH.md)；下面的维度是创作工具，不是已验证的心理分类。

## 先分清谁的偏好

作品的读者关注、叙述者的注意力、角色自己的身体态度、另一角色的吸引，可以不同。读者喜欢未穿假肢的轮廓，不表示主角讨厌假肢；主角喜欢被看，不表示她同意照片被转发。不要把一种偏好写进全部人物。

从当前请求与前文取出已有信息，只补会明显改变成品的缺项。以下选项可组合，不要求用户填写问卷，不设每章描写配额：

| 关注维度 | 可选择的内容 | 防止偷换 |
|---|---|---|
| 形态与差异 | 不对称、保留段、终点、存在但外观改变的部位 | 越短、越多、越明显不自动越有吸引力；不补伤口或疤痕 |
| 动作与身体经验 | 静止、伸展、换姿势、完成任务、尝试后调整 | 熟练与受阻都可被关注；受阻不必演成失去决定权 |
| 衣着与材质 | 遮盖、贴合、松垂、改衣、装置与织物的轮廓 | 选择须符合实际支撑；被遮住的皮肤不算眼前所见 |
| 装置与切换 | 穿戴、取下、装置本身、外观与用途的不同偏好 | 喜欢残肢不等于排斥假肢，喜欢义眼外观不等于它有视觉 |
| 关系与回应 | 被发现的注视、自主展示、调侃、互相欣赏、犹疑、拒绝 | 喜爱、好奇、允许观看、允许触碰、允许拍摄和传播分别成立 |
| 感知与视角 | 自我感受、熟人记忆、初见观察、触觉或声音 | 只写已建立的感觉；不拿缺失部位承担物理动作 |
| 作品强度 | 日常背景、局部停留、全场集中观察、长期主题 | 服从具体任务；正文、非露骨恋爱和照片可各有强度，不默认升级为露骨内容 |

用户只说“细致”时，保留现有身体事实，选本场可见且与视角相连的细节。用户已经明确对象、穿戴状态与浓度时直接执行，不能用“受众复杂”拖延写作。

## 从注视进入关系

按本场需要选择以下环节，可停在其中任何一步，不把它写成固定四段戏：

1. **谁先注意或发起**：旁观者停留，当事人换姿势给人看，伴侣提起上次挑的衣服，都能成为起点。
2. **当事人可知的反应**：只有能看见、听见或推断的线索才进入限知叙述。另一个人是否紧张或喜欢，由动作、对白和已有经验支持。
3. **具体回应**：继续、转过来、提出拍摄角度、纠正称呼、暂停、拒绝、误会或没注意到。回应不必是完美沟通，也不自动成为羞耻或治愈。
4. **留下什么**：约定、兴趣、未解决的分歧或普通物件的位置。下一场可以记住它，不必每次重问所有问题。

关注局部不自动意味着把人等同于局部；判断对方能否作出实际选择、被听见并改变互动。反过来，一句“我尊重你”不能抵消随后无视要求的行为。允许人物越界、误判或冲突，叙述不替一方宣布另一方一定喜欢；纠正、后果和关系走向服从具体故事。

陌生人的注视、熟人玩笑、私下照片、公开展示、触碰与照护不是一个通用许可。已有默契通过自然行为表现；存在疑问或发生改变时，让确认与回应对应这件事。人物可以选择不解释，求助也不应被作者默认写成展示身体或提供照片的交换条件。

## 当事人自己的吸引与愿望

让人物能够选择衣服、设备、拍摄、约会、自己喜欢的对象和不想做的事；这些选择可以直接围绕她或他自己的身体，不必额外安排工作成就来证明主体性。自我欣赏可以与疲劳、麻烦或今天不想被看并存。

喜欢别人的身体与想拥有同一种身体分开；身体体验的想象不自动产生诊断。残疾角色也可能是关注者，女性、同性伴侣或不同性别角色都不需要特殊解释才可出现。不要按研究样本的性别排除替用户改配对。

## 审美与实用意见不一致

甲喜欢某种轮廓，乙今天为了舒适选择另一种穿法；两者都可保持真实。先写各自正在做的选择，再写商量、失望、玩笑或搁置，不靠摘下装置、改变身体或完成额外任务证明爱情。

熟悉的伴侣不会永远像第一次见面。可延续颜色、衣型、动作与共同记忆，也可发现新的细节；持续吸引不需要每次病史揭露、失衡或亲手穿衣。允许关系中有未解决的意见与短暂失望，不把任何不理想反应都改成成熟示范。

表达方法见 [身体关注的写法](../writing-natural/body-attention-methods.md)，完整局部场景见 [原创例集](../writing-natural/devotee-examples.md)。

## 3.0 可选关注配置：不是所有角色的统一性格

用户明确给定或作品已有长期取向时，内部可以记录 `AUDIENCE_FOCUS`（所关注的形态／动态／衣着／辅具／关系／困难）、`ATTENTION_DENSITY`（自然融入／重点突出／全场焦点）、`VIEWPOINT_SOURCE`（谁观察以及信息来自哪里）。这些属于作品层，不属于 `BODY_STATE`，也不是对读者的心理诊断。不要求每次开写前问卷，不按字数或频次强塞关键词。

身体吸引可以在初见、共同活动、穿搭选择、约会、互相拍照和长期相处中持续存在；关系熟悉后不必复演“第一次发现身体”的震惊。身体自我欣赏可以通过自己选择镜头、服饰、展示方式、外观义肢或不佩戴假肢体现；也允许今天拒绝拍照、拒绝触碰、不同意公开。被注视、被触碰、拍摄和传播属于不同范围的许可。

作品明确偏重困难与窘迫时，应检查细节是否真实而有张力，同时保留人物对行动、帮助和关系的决定权；喜欢观察困难不等于要求角色每次失败或被剥夺能力。任何截肢简称和身体层级都不能自动决定人物偏好。
