# Ocular Loss

## 1. 先锁三个独立维度

每一侧眼睛分别记录：

1. `GLOBE_STRUCTURE`：天然眼球结构是完整、改变/部分保留、整体缺失还是未知；
2. `VISION`：视觉是否存在、受限或缺失；
3. `OCULAR_DEVICE`：美容义眼片、外部义眼或其他装置当前是否佩戴及其类型。

这三个维度不能互相推导。

### 典型区分

- `GLOBE_STRUCTURE=intact + VISION=present`：天然眼球完整且有视觉；
- `GLOBE_STRUCTURE=intact/altered_or_partially_retained + VISION=absent`：天然眼球仍有结构但失明；外观可以正常、乳白、浑浊、闭眼等，只有用户指定才写具体；
- `GLOBE_STRUCTURE=absent + OCULAR_DEVICE=worn`：天然眼球整体缺失，当前佩戴外部外观义眼；
- `GLOBE_STRUCTURE=absent + OCULAR_DEVICE=off`：天然眼球整体缺失，当前未佩戴外部义眼。

“乳白浑浊失明”默认只说明外观 + 视觉功能，**不等于眼球整体缺失**。

## 2. 不自动诊断外观原因

用户说“乳白、浑浊、失明”时，可以直接使用描述性视觉语言。除非用户给出病因或任务需要可靠医学来源，不要自行给出角膜、晶状体、视网膜等具体诊断。

## 3. 装置与手术状态不要混用

“义眼”不足以确定手术类型。天然结构可能完整、改变、部分保留或整体缺失；`GLOBE_STRUCTURE` 必要时附文字说明，不用单一布尔值掩盖差异。

- 眼球摘除（enucleation）、眼内容剜除（evisceration）与眶内容剜除（exenteration）涉及的保留组织不同，不能共用一个眼窝外观。
- 美容义眼片／cosmetic shell 可以覆盖仍存在的眼部结构；失明不自动等于使用这种装置。
- 眶内植入物与日常可取下的外部义眼不是同一物件。典型外部义眼是贴合的壳状假体，不是把完整球体塞入眼窝。
- 眼睑、结膜、泪液和装置表面的状态分别判断。装置表面可能湿润，不等于假体自行分泌眼泪；普通人工虹膜／瞳孔图案不随光线主动收缩。

仅在任务涉及这些差异时展开，不能从一个称呼擅自给人物指定手术史。依据与范围见 [来源说明](../docs/SOURCES-AND-DESIGN.md)。

## 4. 义眼与外观装置

普通外部义眼主要恢复外观，不恢复缺失眼视觉。佩戴/摘除是场景状态；未戴义眼也不自动等于新鲜伤口、血腥洞口或夸张黑洞。

义眼可能有有限外观联动，但不要默认完全复制天然眼球运动。科幻/魔法义眼若能看见，登记传感、连接、视野、能源和失效边界。

## 5. 单眼视觉写作

单眼角色依赖另一只有视觉的眼睛以及头部移动、运动视差、遮挡、大小、阴影和经验等线索完成任务。不要固定写成“完全没有距离感”。陌生环境、高速接物、某些精细定位任务可能更容易暴露差异，但程度属于个体变量。
同时观察两侧、快速转头后判断近处落点、复杂运动中的患侧来物，可以形成真实的任务阻力。写明哪侧需要补看、人物怎样转头或改站位、是否有时间这样做；训练降低某些失误，不保证突发情境永不漏看。单眼视觉不必每场都失手，发生失误时也要让物件位置和后果连续。
若仍有视觉的一眼还设有高度近视，另记其矫正前后能力与眼镜当前状态。摘掉眼镜、镜片沾水或眼镜不在手边可改变本场任务；不把单眼和近视合并成一个笼统的“看不见”，也不擅定具体度数或距离。

## 6. 外观与配件

分别记录：

- 哪侧天然眼球结构完整、改变/部分保留、整体缺失或未知；
- 视觉能力；
- 义眼/美容义眼片当前戴/未戴；
- 失明眼若仍存在，其外观；
- 眼镜、护目镜、眼罩是否佩戴以及用途；
- 是否有世界观视觉设备。

眼镜不自动代表隐藏义眼，眼罩也不是所有眼部残疾角色的标配。

## 7. 视觉提示词

### 天然眼球结构仍存在但失明

优先正向锁定：

`left/right natural eye structure present, blind in that eye, [opaque/clouded/milky appearance only if specified], other eye state ...`

同时避免 `empty socket / missing eyeball` 一类错误结构。

### 天然眼球整体缺失

明确：哪侧天然眼球整体缺失、外部义眼当前状态、外部覆盖以及愈合后非血腥外观（若场景如此）。不要生成第二只正常天然眼。

## 8. 连续性

`OCULAR_SIDE / GLOBE_STRUCTURE / VISION / OCULAR_DEVICE` 四者逐场景跟踪。已取下或遗失的义眼不会无过渡恢复；镜像自拍也不改变角色自身侧别。

## 9. 常见错误

- 把“失明”自动变成“眼球整体缺失”；
- 把乳白/浑浊眼画成空眼窝；
- 把“义眼”一词自动解释成某一种手术；
- 普通外部义眼恢复视觉；
- 义眼佩戴状态自动跳变；
- 左右侧镜像漂移；
- 未戴义眼被画成第二只正常眼；
- 长期愈合状态被画成血腥开放伤；
- 用一个统一模板描述所有单眼角色的距离判断。
