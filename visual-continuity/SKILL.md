# 视觉提示词与连续性

## 先识别任务
默认交付可直接复制的中文自然语言提示词，不自动生成图片。用户指定平台或语言时再适配；不凭空添加模型版本、权重、种子、参考图 ID 或无依据的参数。用户只要提示词时，不附分析过程。
需要新人物设定而身体侧别、层级等关键事实缺失时，只询问会改变画面的缺项；已有上下文能回答就继续。小配件、光线等可作合理创作选择，不能顺手改身体事实。
参考 [输出模板和完整案例](prompt-template.md)。

## 画面之前先锁状态
对每个人独立确认角色自身左右、结构保留范围、残肢终点、功能、当前器械与服装。眼球存在但失明、双腿存在但瘫痪都不能画成结构缺失。
固定身份可包括发型、脸型、体态、衣着特征与器械外观，但只使用已有设定或本次明确创作的设定；后续保持相同措辞，不把“同一人物”当唯一身份约束。
镜头中的左／右不是解剖左右。正常正面相对时角色自身左通常出现在画面右；背面、转身与真实镜面反射需按实际构图判断，不机械替换词。镜中影像也不改变角色本人的缺失侧。

## 提示词组织
按当前画面编排成连贯文本：人物与动作 → 构图及空间 → 可见身体结构 → 器械和服装 → 光线与材质 → 少量关键约束。
身体事实使用明确正向描述：保留什么、到哪里、由什么支撑。给用户的提示词优先用日常称呼，例如“左腿在大腿处截肢，保留大腿残肢，天然左膝、小腿和足缺失”，不能只写“无小腿”。内部仍按准确层级核对。功能状态写明，但不要把不可见诊断伪装成视觉纹理。
每张图是某一瞬间。动作提示词说明此刻的姿势、接触点、重心和手占用，避免要求一张图同时完成坐下、脱假肢和站起来；连续动作改用分镜。

## 衣物与器械轮廓
残肢范围内衣物仍有体积；空袖、裤腿、袜筒从真实支撑终点以后松垂、折叠或固定。长裙遮住时不要求看穿衣料。
连裤袜共享腰胯与两个腿筒，不等于两只独立长袜。说明缺失侧覆盖残肢后如何处理；完整瘫痪腿仍撑起完整衣物轮廓。假肢穿入后按接受腔、关节、支柱、外罩和假脚的实际结构塑形。
同一角色可因工作、约会、天气、舒适度或审美选择不同处理：让空袖／裤腿／袜筒垂落、折入、固定、改短，或改穿裙装、独立丝袜与适合当场装置的衣物。不要把每张图的空置衣料都自动卷起；变化须与本张穿戴状态一致。
高度近视若是角色设定，提示词可写眼镜款式、当前是否佩戴以及可见的行为与视线；不要把未佩戴眼镜当作天然眼球缺失，也不要仅凭镜片外观编造度数。
无人工膝的刚性棍腿不能在膝处弯曲。义肢的手与天然手分清，已取下的假肢或义眼应在设定位置，不能继续出现在身上。
普通义眼不恢复视力；眼部结构、外观装置、眼睑与覆盖分别描述。未知手术状态不编造内部组织。

## 构图与质感

明确身体审美取向时，把关注转为可画的景别、角度、姿态、衣料和光线，按需见 [受众关注维度](../writing-character/devotee-audience.md)。细节照、半身与全身可以各有焦点，不因取向而统一裸露、中心化残肢、摘掉装置或加苦难表情。人物自主展示可通过选衣、摆姿势、面对镜头或调整画面呈现；不可见的意愿不靠心理标签画出来。多图需要改变可见关注，仍逐张保留同一侧别、终点与既有外貌。
先选能呈现任务的景别与视角，留出关键物件的空间；细致身体描写不等于每张都以残肢居中。可用衣料走势、姿势、器械位置表达状态，不强制裸露、剖面或伤口。
光源方向、明暗层次和材质回应同一环境。区分皮肤、织物、硅胶、金属、塑料和橡胶的反光与表面；不要靠“超高质量、震撼、完美”替代可画信息，也不要为真实感强加污渍、破损或疤痕。
画风由用户或已有作品决定。写实、漫画、水彩等只选与需求一致的表达，不同时堆放互相冲突的风格。

## 多图、多人和分镜
每个人单独绑定外貌、缺失侧、器械和衣物。用姓名加稳定特征区分，避免一串残疾标签被模型任意分配。
每张可复制提示词都必须独立完整：重复必要身份、外貌、身体硬状态、当前器械、服装、动作、场景与关键约束，再说明本张变化。不得依赖前一段公共前缀，不能只写“同上”“保持上图”“另一侧同前”。多格合成一张图时，可在这一张提示词内部共用设定；多张分别生成时，各张重复必要设定。性格只转成可见表情与行为，不强塞不可画的心理标签。镜头省略可行，但穿脱或转移要在邻格信息中有依据。
用户提供参考图时说明哪张用于身份、哪张用于画风或设备，并明确本次允许改变的部分；没有参考图不声称已引用。将小说片段转提示词时只提取当前画面可见内容，潜台词通过动作、距离与表情表现，不照抄心理独白。

## 约束与修改
正向结构为主，补充本图最容易混淆的限制，例如“左袖在残肢终点后折平，不生成左前臂或天然手”。不以大串否定词掩盖前面相互矛盾的姿势。
通用工具默认把约束写进自然语言；平台确有独立负面提示入口且用户需要时再分栏。不要假设“无额外肢体”就能替代具体人体结构。
用户提供错误成图时先查看实际图像，再定位要改的区域。局部修改指令说明错误、目标和应保持的身份／画风／其他结构；没见图时只给条件性修正，不编造已发现的错误。
本技能验收默认是提示词文本。只有拿到成图才检查实际画面；遮挡部位记为无法直接验证，不能因为提示词正确就宣称绘图成功。
