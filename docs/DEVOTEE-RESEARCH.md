# 慕残与创作受众：研究记录

检索与核读日期：2026-10-08。用途是改进中文创作技能，不是诊断工具、人口普查或市场规模报告。以下分别标明研究发现、当事人经验和本仓库提出的创作方法；三者不能互相冒充。

## 范围与检索方法

围绕 devotee / devotism / acrotomophilia、disability and desire、amputee perspectives、慕残与受众检索，优先核对原始论文的方法和招募条件；再对照公开的第一人称关系经验。收录下表可核读的研究，不把转载次数、社群发帖频率或搜索排名当作流行程度。检索涉及英语与西班牙语资料；没有开展访谈、问卷或私域社群采样。

本次找到的定量研究包括数百人与数千人样本，不能笼统称为“小样本研究”。主要局限是有目的的招募、网络社群覆盖和性别排除；人数增加不会自动修复代表性问题。此次没有取得能代表中文创作受众的调查，也没有作品阅读、付费、留存或偏好排名数据。

## 概念边界

- “慕残”在中文交流中可能指身体审美、恋爱吸引或性吸引。先读用户实际任务，不给每次残疾人物创作追加性意味。研究中的 devotee 标签通常讨论对残疾或相关身体特征的吸引，研究者对范围的定义并不一致。
- 对他人身体的吸引、欣赏自己的身体、想象自己体验某种身体状态、希望改变自身身体，分别记录。它们可能在某个个体身上重合，不能从其中一项推出其余项。旧文献把 devotee、pretender、wannabe 放在同一框架中，不表示它们是一个心理过程。
- 非典型兴趣与精神障碍有区别；APA 的 2013 年说明明确区分二者 [S4]。此处只保留概念边界，不把读者偏好转成诊断，也不把文学设定当作临床依据。
- “当事人”与“慕残者”不是互斥身份。“没有残疾的男性喜欢截肢女性”是某些资料的研究对象，不是仓库的默认人物关系。

## 结论强度与资料缺口

可以确信这些来源无法证明一个统一的受众画像。它们也提供了差异存在的证据：关注的对象不同，当事人对关系中的身体关注可能欢迎、拒绝、犹疑或随关系调整 [S1, S3, S5–S7]。不能把欢迎理解为没有边界，不能把拒绝解释成身体接纳不足。

中文受众、女性及性别多样受众、非网络参与者、残疾慕残者的阅读偏好仍是本次研究缺口。失明、肢体完整但功能受限、先天肢体差异等，也不能借截肢资料代填。缺少证据表示未知，不表示这些人或偏好不存在。

## 从研究到技能：编辑决定

以下是本仓库的创作推断与设计选择，没有经过受众实验验证：

| 发现或限制 | 本次改进 | 评审证据 |
|---|---|---|
| 研究对象与偏好范围不统一 | 用可组合的关注维度替代固定性别、身体类型或人格画像 | 已知偏好被落实，未知偏好不靠统计刻板印象补齐 |
| 欣赏、关系选择与自身身体体验不能互相推出 | 将作品取向与角色状态分开；不同愿望分别建立 | 不因读者喜欢某种身体就改变主角的身体或意愿 |
| 当事人的反应并不一致 | 让发起、回应、调整与取消进入具体场景 | 欢迎与拒绝都能成立；不用宣言替代实际选择 |
| 仅有身体吸引不能解释全部关系 | 补入长期注意力、协作和审美分歧 | 吸引可持续，普通矛盾也持续，不靠每章重复揭露 |
| 缺少作品效果数据 | 新增原创正例与行为案例，再做有限的实际试用 | 静态校验、模型试用与受众反馈分别报告 |
