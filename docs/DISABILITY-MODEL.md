# 身体状态与残疾创作模型

这份文档定义仓库在创作任务中使用的**状态语言**。它不是诊断手册，也不要求人物使用某一种自我称呼。

## 1. 最重要的拆分：结构存在与功能能力

同一身体部位至少有两个问题：

- **PRESENCE / STRUCTURE**：它是否存在，保留到哪里，哪些关节/器官仍在？
- **FUNCTION / CAPACITY**：它能否主动运动、承重、抓握、感知、看见或完成某项任务？

因此：

- 双腿完整但瘫痪：两条腿仍然占据裤腿/丝袜/裤袜的体积，不能画成空裤腿；运动和承重能力另行记录。
- 一只眼完整但失明、浑浊或乳白：眼球仍在，不能自动改成眼球缺失或空眼窝。
- 手仍在但握力弱/关节活动受限：服装和轮廓按“存在”处理，精细操作按“功能”处理。
- 先天肢体差异与后天截肢不是同义词；除非用户给出，不自动补手术疤痕、幻肢或病史。

## 2. 推荐状态维度

### LOCKED

- `BODY_STATE.STRUCTURE`：天然结构存在/部分存在/缺失；侧别；保留段；保留关节。
- `BODY_STATE.FUNCTION`：主动运动、承重、抓握、关节活动范围等任务能力。
- `SENSATION_PROFILE`：触觉、麻木、过敏、幻肢/幻痛等，只记录已建立内容。
- `VISION_BASELINE`：每只眼的“结构存在”与“视觉能力”分别记录。
- `PROSTHESIS_CAPABILITIES`：每件装置真实能力边界。
- `TASK_SKILLS`：平地、楼梯、转移、穿衣、地面恢复等按任务分项。
- `VISUAL_INVARIANTS`：侧别、残肢终点、固定外貌等。
- `WORLD_EXCEPTION`：魔法/科幻改变了什么、没有改变什么、代价和失效条件。

### SCENE

- `PROSTHESIS_STATE` / `AID_STATE`：正在用、未用、损坏、放在哪里。
- `MOBILITY_MODE`：这一刻实际采用的移动方式。
- `SUPPORT_POINTS`：脚、假脚、拐杖、轮椅、墙面、扶手等当前支撑。
- `HAND_OCCUPANCY`：每只可用手此刻是否被占用。
- `CLOTHING_STATE`：衣物种类、穿戴、折叠、空置和器械覆盖。
- `POSITION_STATE`：站、坐、床边、地面、轮椅中等。
- `ENVIRONMENT_STATE`：楼梯、雨雪、湿滑、拥挤、狭窄、战斗等。
- `FATIGUE_OR_DISCOMFORT`：只记录当前确实存在的疲劳、摩擦或不适。

## 3. 术语边界

- **残肢 / residual limb**：缺失后保留下来的身体段；描述时还要说明侧别和保留范围。
- **残端**：残肢最远端的区域，不能把“残端”当成整段残肢。
- **断肢**：更适合表示已经与身体分离的肢体或事件，不应长期拿来替代“残肢”。
- **残态**：可作为创作工作流里的口语化“当前身体/视觉状态”简称，但不是精确解剖层级；内部应落到具体状态字段。
- **跛行 / 一瘸一拐**：描述步态不对称，不是“任何少一条腿角色”的同义词。没有假肢、只有一条天然承重腿时，角色可能选择跳移、拐杖、轮椅、扶物或其他方式，而不一定存在可称为跛行的交替步态。

## 4. 结构层级只在需要时精确

下肢可按任务区分足部部分缺失、踝部、膝下/经胫、膝离断、膝上/经股、髋部等；上肢可区分手指/部分手、腕部、肘下/经桡、肘部、肘上/经肱、肩部等。

如果用户只说“少了一条腿/一只手”，而当前任务不需要更精确：保持泛化，不擅自选层级。只有在动作、假肢结构、服装终点或画图必须明确时，才使用最少必要假设或已有专项。

## 5. 服装拓扑

衣物不是身体标签，而是一个有支撑关系的结构：

`衣物通道 = 天然结构支撑 / 残肢部分支撑 / 假肢支撑 / 无支撑空置 / 被折叠或改造`

这套模型适用于袖子、裤腿、袜子、丝袜、长筒袜、裤袜/连裤袜、leggings、手套和鞋。

尤其注意：

- **独立长袜/过膝袜/丝袜**：本来就是左右分开的单件，角色可以只穿一只。
- **裤袜/连裤袜/tights**：腰胯部分与两条腿筒属于同一件衣物。缺失侧可以覆盖残肢后形成空袜筒、折入/固定、经过改造剪短，或被假肢撑起；不能把它当成普通“单独一只袜子”而忘记共享腰部结构。
- **完整但瘫痪的腿**：仍然把裤袜/裤腿撑成完整腿形，只有功能状态不同。
- **假肢穿在衣物内部**：裤腿或袜筒可能被接受腔、人工关节、支柱和假脚撑起；外观不应自动等同天然腿。
- **空袖/空裤腿/空袜筒**：真正无支撑的部分从天然残肢或假肢支撑终点以后开始，受重力、风、动作、折叠和固定方式影响。

## 6. 动作类型不要混成一个词

- **步行/假肢步态**：存在可重复的步态周期；可对称也可不对称。
- **单腿跳/连续跳移**：由一条承重腿反复起落；检查落点、支撑、手占用、地面与疲劳。
- **短跳转移**：床边、椅边或狭小空间中的几次重定位，不等同长距离连续跳。
- **扶物挪动**：以墙面、家具、扶手或他人作为额外支撑点。
- **轮椅移动**：手动、电动或由他人协助，另行检查转移与地形。
- **坐姿挪动/臀部移动**：用于床面、地面等低位环境。
- **爬行/跪行/地面移动**：先确定哪些身体表面接触地面；残肢是否承压、是否有保护、双手是否可用都不能默认。
- **转移**：站↔坐、床↔椅、轮椅↔座椅、地面↔站立等，是独立任务，不要用一句“她灵活地过去了”跳过必要支撑。

## 7. 器械不是能力开关

每件辅具/假体按任务需要记录：状态、控制、支撑、手占用、适用任务、维护和失效条件。高级、昂贵、魔法或科幻只代表设定不同，不能自动获得未声明能力。

简单刚性“棍腿/peg/stilt”也应明确结构：例如接受/固定部分 + 刚性支柱 + 末端接触件；若没有膝关节，就不能在膝位置自然屈曲。坐姿、楼梯和步幅如何处理仍由具体长度、固定方式、训练和场景决定，不写成唯一动作序列。

## 8. 人物层

身体差异可以改变节奏、风险、工作流、服装选择、社会互动和关系，但人物仍应有与身体无关的目标、审美、职业、兴趣、脾气和价值判断。身体细节出现多少由当前场景功能决定，也允许感官观察与身体审美，不固定配额或反复提醒读者身份。
