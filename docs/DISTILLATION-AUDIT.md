# Archive 全文蒸馏审计

本文件记录 v2.1 对历史材料的“保留 / 泛化 / 拒绝”决策。它的目的不是给 archive 判优劣，而是防止以后再次把某篇小说、某个角色或某次补丁验证中的偶然规则升级成运行时硬约束。

## 2. 保留为现役硬不变量

这些规则跨来源可迁移，且不是某个角色的个人经验：

1. **结构存在与功能能力分开**：瘫痪的腿仍存在；失明眼球若仍在就不是空眼窝。
2. **侧别与保留结构连续**：镜像、反打、换场景不能让缺失侧或残肢终点漂移。
3. **幻肢属于感觉，不是实体承重点**。
4. **器械有状态和位置**：穿戴、取下、遗失、损坏、维修都需要连续性。
5. **手占用是真实资源**：同一只手不能无过渡同时完成互斥任务。
6. **衣物服从真实支撑拓扑**：天然肢体、残肢和假肢撑起衣料；空置从实际支撑终点后开始。
7. **裤袜是一件共享腰胯 + 双腿筒的衣物**，不能按两只独立长袜处理。
8. **动作类型要准确**：跛行、步行、连续跳、短跳、拐杖移动、轮椅、地面移动、转移不是同一个词的不同写法。
9. **世界观例外有边界**：魔法/科技只覆盖明确登记的限制。
10. **人物心理不是身体标签的函数**。

## 3. 保留为“求解方法”，不保留唯一答案

以下旧材料有价值，但只能泛化成方法：

- 日常任务：`目标 → 可用结构/功能 → 支撑 → 手占用 → 环境 → 器械 → 分步`；
- 假肢/器械适配：`目标 → 试用 → 身体/任务反馈 → 调整 → 再试`；
- 多部位角色：分别维护身体链，再处理资源耦合；
- 信息揭示：每次揭示应改变理解、选择或关系，而不是只补百科；
- 凝视：观察者、社会反应、角色本人反应可以形成多层张力，但层数由场景决定；
- 辅具作为人物物件：可以有磨损、定制、维修和情感意义，但首先仍是工具；
- 战斗：从当前支撑、视野、器械、武器、地形和训练求解，不从“残障”本身推胜负。

## 4. 明确拒绝为通用硬规则的旧材料

下列内容曾存在于历史 archive，现行技能与自动测试应阻止它们再次变成默认事实：

### 移动与器械

- 固定“8 cm 鞋跟极限”或任何从小说提取的统一厘米数；
- “前臂拐/肘拐对单腿角色只能成对使用”的绝对规则；
- 固定上楼、下楼、上车、起身或驾车动作序列；
- 仅凭缺左腿/缺右腿就给出跨地区通用驾驶资格结论；
- “带拐就必须走、放拐就必须跳”的二元规则；
- 公共场合必须用拐、私人空间优先跳的场景公式；
- “拐杖 > 单腿跳 > 爬行”的所谓体面等级。

### 熟练度与身体感知

- 用截肢年限直接映射新手/成熟期；
- 固定“几个月后一定能做到什么”的康复时间表；
- 固定幻肢消失时间、固定诱因或把幻肢当作“接受身体的进度条”；
- 固定“残端红印多少分钟消退就能继续”的临床式操作。

### 人物与关系

- 残障者默认对同情敏感、默认拒绝主动帮助；
- 帮助必须等对方先开口；
- 残障恋爱默认经历“自卑 → 防御 → 依赖 → 接纳”；
- 每个公共场景固定写“观察者凝视 + 路人侧目 + 角色钝感”；
- 群像必须靠互不重复的“残损类型矩阵”区分人物。

### 剧情与世界观

- 残障事实必须在开篇固定字数内亮相；
- 截肢/残障成因必然是全篇最重要悬念；
- 成因必须在 1/3、2/3 或其他固定篇幅节点揭晓；
- 截肢原因默认禁止阴谋化；
- 无功能的残障路人必须按固定概率出现；
- 残障角色战斗力必然全面低于健全角色，或反过来必然获得“补偿能力”。

## 5. 医学与现实事实的来源边界

`disable-skill-pack` 来自小说语料蒸馏。它可以提供创作问题、动作观察点和叙事方法，但**不能单独证明临床事实**。

当作品需要精确的：

- 手术结构；
- 康复时程；
- 伤口/皮肤处理；
- 器械临床参数；
- 法规、驾驶资格或现实制度；

应使用用户明确设定或另行可靠来源。Active Skills 默认保持描述性和任务级，不从小说案例开处方。

## 6. 维护规则

若从历史提交恢复任何旧细节，先标记它属于：

`STRUCTURAL_INVARIANT / FUNCTION_VARIABLE / SCENE_STATE / CHARACTER_VARIABLE / DEVICE_SPEC / WORLD_EXCEPTION / STORY_METHOD / CORPUS_CASE`

只有前三类中得到可靠支持且不与用户设定冲突的内容，才可能成为硬校验。`CHARACTER_VARIABLE` 与 `CORPUS_CASE` 永远不能仅凭出现频率升级为“残障角色默认值”。
